## วิธีติดตั้ง (ต้องมี Python 3.8+ ไม่ต้องติดตั้งไลบรารีเพิ่ม)
แตกไฟล์ zip แล้วเปิด Terminal / Command Prompt ในโฟลเดอร์นี้

### ขั้น 1: เงินจำลอง (ไม่ต้องใช้ key)
```
python main.py
```
แล้วเปิด **http://localhost:8080** ดูแดชบอร์ด ควรรันไว้อย่างน้อย 2–4 สัปดาห์

### ขั้น 2: Binance Testnet (คำสั่งจริง แต่เงินปลอม)
1. เข้า https://testnet.binance.vision → Log in with GitHub → Generate HMAC-SHA-256 Key
2. ตั้งค่า key แล้วรัน:
   - Windows (Command Prompt):
     ```
     set BINANCE_API_KEY=ใส่key
     set BINANCE_API_SECRET=ใส่secret
     python main.py --mode testnet
     ```
   - Mac/Linux:
     ```
     export BINANCE_API_KEY=ใส่key
     export BINANCE_API_SECRET=ใส่secret
     python main.py --mode testnet
     ```

### ขั้น 3: เงินจริง
1. Binance → Account → **API Management** → Create API (System generated)
2. เปิดสิทธิ์ **Enable Reading** + **Enable Spot & Margin Trading** เท่านั้น
   **ห้ามเปิด Enable Withdrawals เด็ดขาด**
3. ตั้ง **Restrict access to trusted IPs only** ใส่ IP ของเครื่องคุณ
4. ตั้ง `max_capital_usdt` ใน config.json (เริ่มต้น 100 USDT = บอทใช้เงินไม่เกินนี้)
5. ตั้ง key แบบขั้น 2 แล้วรัน `python main.py --mode live` แล้วพิมพ์ยืนยัน
6. ต้องรันจากเครื่องในประเทศที่ Binance อนุญาต (IP อเมริกาจะโดนปฏิเสธ)

### เปิดฝ่าย AI (ไม่บังคับ)
สมัคร API key ที่ https://console.anthropic.com แล้วตั้ง `ANTHROPIC_API_KEY` แบบเดียวกับ Binance key
คุมค่าใช้จ่ายด้วย `ai_daily_budget_usd` (เริ่มต้น $0.50/วัน) และเลือกรุ่นที่ `ai_model`

## ค่าตั้งใน config.json
| ค่า | ความหมาย |
|---|---|
| `mode` | `paper` / `testnet` / `live` |
| `risk` | `low` / `mid` / `high` |
| `max_capital_usdt` | เพดานเงินที่บอทใช้ได้ (testnet/live) |
| `max_daily_loss_pct` | ขาดทุนวันนี้เกินกี่ % ให้หยุดเปิดไม้ใหม่ |
| `cash_reserve_pct` | เก็บเงินสดสำรองไว้กี่ % |

| `max_spread_pct` | ส่วนต่างราคาซื้อขายสูงสุดที่ยอมซื้อ (เริ่มต้น 0.5) |
| `max_slippage_pct` | ซื้อแล้วราคาเฉลี่ยแพงกว่าราคาดีสุดได้ไม่เกินกี่ % (เริ่มต้น 0.5) |

## หยุดฉุกเฉิน
- กดปุ่ม "หยุดเปิดไม้ใหม่" บนแดชบอร์ด หรือสร้างไฟล์ชื่อ `STOP` ในโฟลเดอร์ ไม้เดิมยังมี stop loss คุมอยู่
- กด Ctrl+C เพื่อปิดโปรแกรม คำสั่ง OCO บน Binance ยังทำงานต่อ
- ถ้าจะขายทุกอย่างทันที ให้ทำในแอป Binance เอง

## ข้อจำกัดที่ควรรู้
- ต้องเปิดเครื่องทิ้งไว้ บอทถึงทำงานตลอด 24 ชม. (บน VPS ที่ติดตั้งด้วย install.sh บอทเปิดเองตอนรีบูตและตอนล่ม)
- ทดสอบกับ Binance ปลอม (mock) แล้ว แต่ยังไม่ได้ทดสอบกับเซิร์ฟเวอร์จริง ต้องผ่าน testnet ก่อนเสมอ
- เป็น Spot อย่างเดียว ไม่มี Futures/เลเวอเรจ (ตั้งใจไม่ใส่ เพราะล้างพอร์ตได้)

## ดูแดชบอร์ดจากมือถือ (ปลอดภัย 2 ชั้น)
1. **Tailscale** (ฟรี): ต่อ VPS กับมือถือเป็นเครือข่ายส่วนตัวที่เข้ารหัส คนนอกมองไม่เห็นพอร์ตแดชบอร์ดเลย
2. **รหัสผ่านแดชบอร์ด**: ตั้ง `DASHBOARD_PASSWORD` (อย่างน้อย 10 ตัวอักษร) ใส่ผิด 5 ครั้งล็อก 15 นาที
รันด้วย `python3 main.py --host 0.0.0.0` (ถ้าไม่ตั้งรหัสผ่าน โปรแกรมจะไม่ยอมเปิดสู่เครือข่าย)

## Binance TH (บัญชีคนไทย)
ตั้ง `"exchange": "binance_th"` ใน config.json (ค่าเริ่มต้นตอนนี้) บอทจะเทรดคู่เงินบาท (THB) ผ่าน api.binance.th
- Binance TH ไม่มีคำสั่ง OCO บอทจึงเฝ้าราคาเองทุก 30 วินาทีแล้วขายเมื่อถึงจุดตัดขาดทุน/ทำกำไร (ต้องให้บอทรันอยู่)
- ไม่มี testnet: ใช้ paper ก่อน แล้วค่อย live
- `max_capital_usdt` จะเป็นหน่วยบาท
- ตรวจการเชื่อมต่อและยอดเงินโดยไม่ซื้อขาย: เมนู manage.sh ข้อ 10

## แจ้งเตือนเข้า LINE
บอทส่งเข้า LINE เมื่อ: เริ่มทำงาน, ซื้อ, ขาย (บอกกำไร/ขาดทุน), ขาดทุนต่อวันถึงเพดาน, มีปัญหาติดกัน 3 รอบ, ค้างจนต้องรีสตาร์ต, กลับมาปกติ และ **สรุปทุกคืน 3 ทุ่ม**
ถ้าคืนไหนไม่ได้รับสรุป = บอทหรือ VPS อาจดับ ให้เข้าไปเช็ก

ตั้งค่า (ทำจากมือถือได้):
1. เข้า https://developers.line.biz/console/ ล็อกอินด้วย LINE → Create provider (ตั้งชื่ออะไรก็ได้)
2. สร้าง LINE Official Account (หน้าเว็บจะพาไปสร้าง) แล้วเปิด **Messaging API** ใน LINE Official Account Manager → Settings → Messaging API
3. กลับไปที่ channel ใน LINE Developers Console
   - แท็บ **Basic settings** → เลื่อนลงไปคัดลอก **Your user ID** (ขึ้นต้นด้วย U)
   - แท็บ **Messaging API** → **Channel access token (long-lived)** → กด Issue แล้วคัดลอก
   - สแกน QR ในแท็บ Messaging API เพื่อ **เพิ่มเพื่อน** บัญชีบอท (ไม่เพิ่มเพื่อนจะส่งไม่ได้)
4. บน VPS: `bash /root/ai_trading_company/manage.sh` → ข้อ 11 วาง token และ user ID → บอทจะส่งข้อความทดสอบให้

แพ็กเกจฟรีของ LINE OA ไทยส่งได้ 300 ข้อความ/เดือน บอทหยุดส่งเรื่องทั่วไปที่ 280 (เปลี่ยนได้ด้วย `line_monthly_limit` ใน config.json) และเก็บที่เหลือไว้ส่งเรื่องด่วน

## แจ้งเตือนเมื่อบอทดับ / ทำงาน 24 ชม.
- systemd เปิดบอทใหม่เองทุกครั้งที่ล่ม/VPS รีบูต และมีตัวเฝ้า (watchdog) รีสตาร์ตเองถ้าค้างเกิน 15 นาที
- เปิดกลับมาแล้วบอทจะเช็กว่าดับไปนานแค่ไหน แล้วส่ง LINE บอก (ถ้าสั่งปิดเองด้วย manage.sh จะไม่แจ้ง)
- กด "สถานะ" ใน LINE: บอกว่าระบบออนไลน์ไหม เปิดต่อเนื่องกี่ชั่วโมง สแกนล่าสุด/รอบถัดไป แต่ละส่วนทำงานไหม แล้วตามด้วยพอร์ต
- VPS ดับทั้งเครื่อง บอทแจ้งเองไม่ได้: ใช้ healthchecks.io (ฟรี) manage.sh ข้อ 18 → บอทส่งสัญญาณชีพทุกนาที ถ้าเงียบเกินกำหนดเว็บนั้นแจ้งเตือนทางอีเมล/แอปให้

## ที่ประชุม AI + ความเร็ว + คุมความเสี่ยงรวม
- **ประชุม 2 AI**: Gemini วิเคราะห์อิสระก่อน → Claude อ่านความเห็นแล้วตัดสิน ทั้งคู่ให้ความมั่นใจ 0-100 รวมเป็น "ความมั่นใจของที่ประชุม"
  เห็นตรงกัน = ไม้เต็ม · เห็นต่าง = ไม้เล็กลง (40-100% ของปกติ) · รวมต่ำกว่า `min_conviction` (55) = ไม่ซื้อ · Gemini ค้านแรง = ไม่ซื้อ
- **ช่องทางด่วน** ทุก 5 นาที (`watch_every_min`): เช็กเหรียญที่เกือบผ่านเกณฑ์ + ที่ Gemini บอกน่าจับตา ถ้าเพิ่งเข้าเงื่อนไขส่งเข้าที่ประชุมทันที ไม่ต้องรอรอบสแกนเต็ม
- **สแกนขนาน** (`scan_workers` 6): ดึงข้อมูลหลายเหรียญพร้อมกัน รอบสแกนเร็วขึ้นหลายเท่า
- **ความเสี่ยงรวมพอร์ต (portfolio heat)**: ถ้าทุกไม้โดนตัดพร้อมกันต้องเสียไม่เกิน ต่ำ 2% / กลาง 4% / สูง 6% ของพอร์ต (`max_portfolio_heat_pct`) ไม้ที่ล็อกกำไรเหนือทุนแล้วไม่นับ
- **ไม้ใหม่ต่อรอบ** ไม่เกิน ต่ำ 1 / กลาง 2 / สูง 3 (`max_new_per_round`) เพราะเหรียญมักร่วงพร้อมกันตาม BTC

## สมองเทรด
ฝ่ายวิจัยวิเคราะห์ทุกเหรียญด้วยเช็กลิสต์ 10 ข้อแบบนักเทรดมืออาชีพ (ta.py) คะแนนรวม 100:
TF ใหญ่ขาขึ้น 15 · โครงสร้าง HH/HL 10 · EMA20>EMA50 10 · ADX>20 10 · MACD 10 · RSI 45-68 10 · วอลุ่ม/OBV 10 · แข็งกว่า BTC 10 · ห่างแนวต้าน ≥2R 10 · แท่งเทียนยืนยัน 5
หักคะแนน: ไล่ราคา (ห่าง EMA20 >3 ATR), RSI >75, แท่งเทียนกลับตัวขาลง, ติดแนวต้าน
จังหวะเข้า: เบรกแนวต้าน (วอลุ่ม ≥1.5 เท่า) / ย่อแล้วเด้ง (แตะ EMA20 หรือแนวรับ) / ตามแนวโน้ม
จุดตัดขาดทุนตามโครงสร้าง (ใต้แนวรับ/ฐานล่าสุด), เป้าหมาย 2.5 เท่าของความเสี่ยงหรือแนวต้าน, ขนาดไม้ตามความเสี่ยง (ต่ำ 0.5% / กลาง 1% / สูง 1.5% ของพอร์ตต่อไม้)
ทดสอบย้อนหลังด้วยเช็กลิสต์เดียวกันบนกราฟของแต่ละเหรียญ (ไม่แอบดูอนาคต)
แดชบอร์ด: แตะเหรียญ = กราฟแท่ง + EMA20/50 + แนวรับแนวต้าน + กรอบคาดการณ์ราคา + เช็กลิสต์
- เฝ้าไม้ที่ถือทุก 10 วินาที แยกจากการสแกนหาเหรียญใหม่ (สแกนตามรอบความเสี่ยง: ต่ำ 30 / กลาง 15 / สูง 5 นาที) ปรับได้ด้วย `monitor_seconds`
- ล็อกกำไรอัตโนมัติ (trailing stop): กำไรถึงระยะ stop → ย้าย stop มาที่ทุน, กำไรถึง 1.5 เท่า → stop ไล่ตามราคาสูงสุด ปิดได้ด้วย `"trailing_stop": false`
- ฝ่ายวิจัยทดสอบย้อนหลังสัญญาณเดียวกันบนกราฟของแต่ละเหรียญ ได้ "โอกาสชนะ" และ "กำไรคาดหวังต่อไม้"
- ฝ่ายกลยุทธ์ไม่เสนอเหรียญที่ทดสอบย้อนหลังแล้วขาดทุนเฉลี่ย (ตั้งด้วย `min_backtest_trades`, `min_backtest_ev_pct`) และเรียนรู้จากผลเทรดจริงของบอทเอง (ลักษณะสัญญาณแบบไหนแพ้บ่อย ลดคะแนน)
- ไม่ไล่ราคาที่วิ่งห่าง EMA20 มากเกินไป
- AI ตัดสินด้วยหลักนักเทรดมืออาชีพ + สถิติย้อนหลัง + ผลเทรดจริงของบอท
- ทุกฝ่ายบันทึกเหตุผลเวลาไม่อนุมัติ ดูได้ในแดชบอร์ดและพิมพ์ "ไม่อนุมัติ" ใน LINE
- ถือเต็มจำนวนไม้แล้วจะไม่เรียก AI (ประหยัดค่า AI)
- คาดการณ์เป็นการประเมินจากสถิติ ไม่ใช่การรับประกันกำไร

### Binance TH คู่ USDT (~380 เหรียญ)
API ของ Binance TH มีคู่บาทแค่ ~11 คู่ แต่มีคู่ USDT ~380 คู่ (เหรียญที่แอปแสดงเป็นบาทส่วนใหญ่อยู่ในกลุ่มนี้)
- เปลี่ยนด้วย manage.sh ข้อ 15 เลือก USDT (กลับเป็น THB ได้ตลอด)
- เงินจริง: ต้องมี USDT ในบัญชี Binance TH (ซื้อ USDT ด้วยบาทในแอปก่อน) และเพดานทุน `max_capital_usdt` นับเป็น USDT
- วอลุ่มขั้นต่ำต่อวัน (ล้าน USDT): ต่ำ 0.1 / กลาง 0.02 / สูง 0.01 แก้ได้ด้วย `th_usdt_min_vol_m`
- ประวัติเทรดคู่ USDT แยกไฟล์จากคู่บาท

## ♊ ฝ่ายวิเคราะห์ Gemini (ประชุม AI 2 ตัว)

- key ฟรีจาก aistudio.google.com/apikey → `manage.sh` ข้อ 20 · ใน LINE พิมพ์ **ประชุม** ดูผลล่าสุด
