### โหมดทองคำ `gold` (แยกจากหุ้น)
เทรด ETF ทอง **GLD / IAU / GLDM** ถือทีละ 1 ไม้ กราฟรายวัน เสี่ยง 1% ต่อไม้ ตัดขาดทุน 4% เป้า 10% (มีล็อกกำไรตามราคา)
- **แนวโน้มทองเอง**: เหนือ MA200, EMA20 > EMA50, ทะลุจุดสูง 20 วัน หรือย่อในขาขึ้น (RSI2 < 20)
- **ดอลลาร์** (UUP): ดอลลาร์อ่อน = หนุนทอง +20 คะแนน · ดอลลาร์แข็ง = กดดัน −20
- **ดอกเบี้ย** (TLT): บอนด์ขึ้น = ดอกเบี้ยลด หนุนทอง +10 · ดอกเบี้ยขึ้น −10
- **ความกลัวของตลาดหุ้น** (SPY): ตลาดร่วงแรงหรือผันผวนสูง = คนหนีเข้าทอง +15
- ดูภาวะจากทอง (GLD เทียบ MA200) แทน SPY: ทองขาลงชัดจะไม่เปิดไม้ใหม่
- เปลี่ยนเป็นโหมดทอง: manage.sh ข้อ 4 → พิมพ์ `gold`

กฎที่ใช้ทุกระดับ: ไม่เปิดไม้ 15 นาทีแรกหลังตลาดเปิด และช่วงใกล้ปิด · ไม่ซื้อหุ้นราคาต่ำกว่า $5 · spread ต้องไม่เกิน 0.3% ·
ไม่ไล่ราคาที่วิ่งห่าง EMA20 เกิน 3 เท่าความผันผวน · กำไรเป้าหมาย ≥ 2 เท่าของความเสี่ยง · ล็อกกำไรอัตโนมัติ (trailing stop)

เวลาไทยที่ตลาดเปิด: 21:30–04:00 น. (ช่วงฤดูหนาวสหรัฐฯ) / 20:30–03:00 น. (ฤดูร้อน)

- Claude ตรวจซ้ำอีกชั้นแบบคณะกรรมการความเสี่ยง: ค้นข่าวเองด้วย web search (เน้น SEC, Reuters, Bloomberg, CNBC) เช็กตัวเลขโซนซื้อ/จุดตัดขาดทุน/ปันผล แล้วโหวต
- **ซื้อได้ต่อเมื่อ AI ที่ทำงานรอบนั้นไม่มีใครค้าน**: มีตัวไหนบอก ไม่ควรแตะ = ไม่ซื้อ · ความเห็นไม่ตรงกัน = รอ
- ตั้งค่า: `claude_model` (ค่าเริ่ม claude-sonnet-5-5), `claude_max_calls_day` 2, `claude_max_searches` 6 · ใส่ key ที่ manage.sh ข้อ 2

- เมนู manage.sh: 15 สแกน+ส่งเดี๋ยวนี้ · 16 log · 17 ใส่ Gemini key · 18 ทุน/เวลาส่ง
- ปรับเกณฑ์ใน config.json → `"scanner": {"min_dividend_yield": 2.5, "min_revenue_growth": 12, "max_trade": 4, ...}`

## ขั้นตอนก่อนใช้เงินจริง
1. **ขอ API key**: webull.co.th/en/open-api → Get API Key → ได้ App Key + App Secret (อย่าส่งให้ใครในแชท)
2. manage.sh ข้อ 1 ใส่ key → ครั้งแรก**เปิดแอป Webull กดยืนยันการเข้าสู่ระบบ** (2FA)
3. ข้อ 9 ตรวจการเชื่อมต่อ/ยอดเงิน · ข้อ 10 ให้ Webull ตรวจคำสั่งทดลอง SPY $5 (ไม่ซื้อจริง)
4. รันโหมด `paper` (เงินจำลอง $1,000 ราคาจริง) อย่างน้อย 2–4 สัปดาห์
5. แลกบาทเป็น **USD** ในแอป Webull · ข้อ 3 เลือก `live` และตั้งเพดานทุน (เริ่มเล็กๆ เช่น $100)

## หยุดฉุกเฉิน
- ปุ่ม "หยุดเปิดไม้ใหม่" บนแดชบอร์ด หรือสร้างไฟล์ `STOP` ในโฟลเดอร์บอท (ไม้เดิมยังถูกเฝ้า stop)
- ขายทันที: ทำในแอป Webull เอง (บอทจะเห็นตอนเปิดใหม่และปิดไม้นั้นในบัญชีบอท)

## ข้อจำกัดที่ควรรู้
- **บอทเฝ้า stop loss เอง** (หุ้นเศษตั้ง stop บนโบรกไม่ได้ทุกตัว) ถ้า VPS ดับ หุ้นที่ถือไม่มีใครเฝ้า — ตั้ง healthchecks.io (ข้อ 14)
- บัญชีเงินสด: เงินจากการขายใช้ได้หลัง settle (T+1)
- หุ้นถือข้ามคืนอาจเปิดตลาดกระโดดผ่านจุด stop (gap) ขาดทุนมากกว่าที่ตั้งได้
- ทดสอบกับ Webull จำลอง (mock) แล้ว ยังไม่ได้ทดสอบกับบัญชีจริง ต้องผ่านข้อ 9–10 และโหมด paper ก่อนเสมอ
- คำสั่งผ่านแชท LINE ปิดไว้ (LINE OA 1 บัญชีมี webhook ได้ที่เดียว ใช้อยู่กับบอทคริปโต)
